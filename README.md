# 🎵 Spotify Music Player

A modern, Spotify-inspired music player with login authentication and file upload capabilities.

## Features

### 🔐 Authentication
- Username & Password login (min 3 characters each)
- Secure logout functionality
- Recently played history (visible only when logged in)

### 📤 Upload Music
- Upload MP3, WAV, or OGG files
- Add custom cover images (optional)
- Direct playback after upload
- Songs stored in browser library

### 🎵 Music Controls
- Play/Pause, Next/Previous
- Shuffle & Repeat modes
- Volume control
- Progress bar with seek
- Real-time search filter

### 🎨 Modern UI
- Spotify-inspired dark theme
- Green accent color (#1db954)
- Smooth animations
- Glassmorphism effects
- Responsive design

## Quick Start

1. Open `index.html` in any modern web browser
2. Click **"Login"** to create a session (username/password)
3. Click **"Upload"** to add your own songs
4. Enjoy the pre-loaded sample tracks
5. Use search to filter songs by title or artist

## Sample Tracks

Includes 3 pre-loaded demo songs:
- Lost in the City - Lo-Fi Beats
- Neon Horizon - Synthwave Engine
- Retro Ambient Wave - Cyber Punk Lab

## How to Upload

1. Click **Upload** button
2. Enter song title & artist name
3. Select audio file from computer
4. (Optional) Add a cover image
5. Click **"Upload Song"**
6. Song plays immediately!

## Login Details

Create any username and password (minimum 3 characters each):
- Example: `user123` / `pass123`
- All logins are stored locally in browser session

## Technical Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Audio**: HTML5 Audio API
- **File Upload**: Blob URL API (browser-based)
- **Icons**: FontAwesome 6.4.0
- **Images**: Unsplash for defaults

## Browser Support

Works on all modern browsers:
- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+
